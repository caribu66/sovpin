Verus Developer Integration & Pinning Service API

          

            SovPin implements both the standard IPFS Pinning Service API (/v1/pins) and the Verus-native VDXF Upload API (/v1/pin/upload).
          


          

            
1. Upload a File or JSON & Receive a Ready-to-Sign VDXF Descriptor:

            
curl -X POST https://dashboard.sovpin.com/v1/pin/upload \
  -H "Authorization: Bearer svp_live_YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "filename": "profile-cmm.json",
    "vdxfUri": "sovpin::storage.pin.descriptor",
    "contentJson": { "verusid": "vreal@", "avatar": "ipfs://..." }
  }'


            
2. Standard IPFS Pinning Service Spec (`POST /v1/pins` & `GET /v1/pins`):

            
curl -X POST https://dashboard.sovpin.com/v1/pins \
  -H "Authorization: Bearer svp_live_YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"cid": "QmdJN78YiEAzh8xQ59YMsMW635cXtr24RDSz6zuJr1NyFk", "name": "genesis-asset"}'
